# 达人社教培 AI 工作台 Demo

面向独立老师、教育工作室与小型教培机构的静态官网演示版。

## 当前功能

- 经营困境互动选择
- 12 大教培业务工作台分类展示
- 四大模块、40 道 AI 经营能力诊断
- 完成诊断后填写微信号查看四维报告
- 三档服务方案与完整交付流程
- 桌面端与移动端响应式布局

## 数据说明

当前版本是纯前端 Demo。用户填写的微信号和诊断结果只保存在其浏览器的 `localStorage`，不会发送到服务器。正式运营前需要接入后端、隐私说明和线索管理系统。

## 部署

仓库可直接通过 GitHub Pages 从 `main` 分支根目录发布。
